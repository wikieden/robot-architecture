讲解

第 1 步：一个关节模组里有什么

现代机器人关节通常做成一体化模组（joint module / actuator），从里到外：

 驱动板（MCU + 功率 MOSFET，跑 FOC）
   └→ 无框力矩电机（BLDC / PMSM，定子 + 转子）
        ├→ 电机端编码器（测转子角度，FOC 必需）
        ├→ 抱闸（断电时锁住，防止手臂掉下来）
        └→ 减速器（行星 / 谐波 / 摆线 / 丝杠）
             ├→ 输出端编码器（测关节真实角度，消掉减速器误差）
             ├→ 关节力矩传感器（可选：Franka、KUKA iiwa 每关节都有）
             └→ 输出法兰 → 连杆

电机：几乎都用无刷电机（BLDC / PMSM）——没有电刷磨损、力矩密度高、配合 FOC 能精确控力矩。电机输出力矩和电流近似成正比：\(\tau_m = K_t\, i\)（\(K_t\) 叫力矩常数）。

问题：电机天生"转得快、力气小"（几千转每分钟、零点几到几牛米），而关节需要"转得慢、力气大"（几十转每分钟、几十到几百牛米）。所以中间要加减速器。

第 2 步：减速比 N 的四个后果

白话类比：自行车变速。骑上坡挂低速档（大减速比）：踩得很轻松，但腿要转很多圈车才走一点。挂高速档反过来。

减速比为 \(N\) 时（电机转 N 圈，关节转 1 圈）：

量 变化 式子
输出力矩 放大 N 倍（乘效率） \(\tau_{\text{out}} = \eta N \tau_m\)
输出转速 缩小 N 倍 \(\omega_{\text{out}} = \omega_m / N\)
反射惯量 放大 N² 倍 \(J_{\text{refl}} = N^2 J_m\)
反驱力矩（从外面推关节需要的力） 大致随 N 增大 摩擦 × N

第三条最反直觉：电机转子本身很轻，但从关节外面看，它像是一个惯量放大 N² 倍的飞轮。N = 100 时放大一万倍。

后果：

  • 碰撞冲击大：手臂撞到东西时，这个"看不见的大飞轮"一下停不住，冲击力大。
  • 反驱性差（backdrivability）：人用手推不动关节，外力也"传不回"电机，没法通过电流感知外力。
  • 力控要额外传感器：所以高减速比的协作臂要么每关节装力矩传感器（Franka），要么用电流 + 模型估计外力（精度有限）。

第 3 步：主流减速方案对比

方案 典型减速比 优点 缺点 谁在用
准直驱（QDD）：大扭矩电机 + 单级行星 约 6–10 反驱好、抗冲击、电流即力矩（本体力感知） 力矩密度受限、电机大、发热 MIT Cheetah 路线的四足（Unitree、MIT Mini Cheetah）、人形腿部部分方案
多级行星 20–100 便宜、刚度好、效率高 有背隙（齿间间隙） 移动底盘、人形大关节
谐波减速（strain wave） 50–160 零背隙、体积小、单级大减速比 柔性（刚度低）、怕冲击、寿命有限、反驱差 协作臂（UR、Franka）、人形手臂
摆线 / RV 30–200 刚度高、抗冲击、寿命长 重、贵 工业重载臂底座关节
滚柱丝杠 / 滚珠丝杠（旋转变直线） 换算后很高 直线推力大、刚度高、类似"人的肌肉" 结构复杂，要配连杆机构 人形膝 / 踝 / 肘的直线执行器（如 Optimus 公开展示的方案）
绳驱 / 腱驱 视设计 电机放在躯干，末端轻 绳伸长、预紧、维护 灵巧手、部分轻量臂
液压 — 功率密度极高 漏油、噪声、维护、效率 老款 Atlas（2024 起改为全电动）

为什么四足普遍选 QDD：腿每一步都在撞地。低减速比让冲击不传成大力矩、电机电流直接反映地面反力（不用力传感器就能"感觉"脚下），控制带宽也高。这条路线出自 MIT Cheetah 的"本体感知执行器"（proprioceptive actuator）设计。

第 4 步：串联弹性执行器（SEA）

在减速器和负载之间故意串一根已知刚度的弹簧 \(k\)：

\[\tau = k\,(\theta_{\text{电机侧}} - \theta_{\text{关节侧}})\]

测两边编码器的角度差就知道力矩——弹簧本身就是力传感器，还能吸收冲击。代价是带宽降低（弹簧会"软"）。Baxter 机器人、部分康复 / 人形机器人用过。

第 5 步：选型怎么算

给一个关节选执行器，至少要算三个数：

  1. 峰值力矩：最坏姿态下扛重力 + 加速度：\(\tau_{\text{peak}} \approx m g\, r + J\alpha\)（\(r\) 为质心到关节的距离）。
  2. 持续力矩：长时间工作时不过热（电机发热 \(\propto i^2 R\)，所以持续力矩远小于峰值）。
  3. 最高转速：任务需要的关节最快速度 \(\times N \le\) 电机额定转速。

再看：力矩密度（N·m/kg，越高越好，因为每个关节的重量都要被前面的关节扛着）、背隙、反驱性、成本。

数学原理

  • 能量守恒推减速器：\(\tau_m\omega_m\eta = \tau_{out}\omega_{out}\)。
  • 动能等效推反射惯量：\(\tfrac12 J_m\omega_m^2 = \tfrac12 (N^2J_m)\omega_{out}^2\)。
  • 焦耳热 \(i^2R\)，热时间常数决定"峰值能撑多久"。

代码里才看得到的 2 件事：
