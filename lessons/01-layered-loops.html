讲解

第 1 步：白话类比：人端一杯水

你端着一杯水走路：

人 多快 机器人里对应的层
大脑想"把水端到桌上" 几秒想一次 L4 任务规划（LLM / 行为树）
眼睛看路、找桌子 每秒几十帧 L3 感知（相机、SLAM）
小脑规划手臂怎么动、脚往哪迈 几十毫秒一次 L2 策略 / 运动生成（VLA、MoveIt）
脊髓反射保持手稳、不洒 几毫秒 L1 关节 / 全身控制（阻抗、WBC）
肌肉纤维收缩 更快 L0 电机驱动（FOC 电流环）

关键是：大脑不管每根肌肉怎么收缩。它只给目标，下面的层负责追上。大脑慢一点、想错一点，下面的反射还能兜住；但如果脊髓反射慢了，水立刻就洒。

第 2 步：为什么不能"一层到底"

假设用一个大模型直接输出电机电流：

  1. 算不过来：电流环要每 25–100 µs 算一次（10–40 kHz）。一个几十亿参数的 VLA 一次推理要几十到上百毫秒，差了 3 个数量级。
  2. 不确定：GPU 推理时间会抖（几毫秒到几十毫秒），而电流环要求每次都准时；迟一次，电机可能过流。
  3. 出错代价不同：上层错了，换个计划就行；下层错了，可能直接撞坏东西或伤人。所以越往下越要简单、可验证。

于是工程上总是：上层给"慢而粗"的目标，下层用"快而简单"的控制器去追。频率每往下一层，大约快 10 倍。

第 3 步：每层跑在哪块硬件上

分层不只是软件概念，每一层对应一块物理硬件：

 L4 任务规划    ── 主控 GPU 或云端          (0.1–1 Hz)
 L3 感知       ── 主控 GPU                (10–30 Hz)
 L2 策略       ── 主控 GPU                (5–50 Hz)
        │  以太网 / 共享内存 / ROS 2 话题
 L1 关节控制    ── 实时核或控制板（RT Linux、RTOS） (200 Hz–1 kHz)
        │  EtherCAT / CAN-FD，每周期一帧
 L0 电机驱动    ── 每个关节自己的驱动板 MCU      (10–40 kHz)
        │  三相 PWM
      电机 ── 减速器 ── 连杆

层与层之间的"接口"就是一条总线加一种消息格式。设计机器人时最重要的决定之一，就是每层之间传什么：

接口 典型内容
L4 → L2 一句子任务语言（"拿起红杯子"）、子目标图像、目标位姿
L2 → L1 一段轨迹 / action chunk：未来 N 步的关节角或末端位姿
L1 → L0 每个关节的目标位置 + 速度 + 前馈力矩 + 刚度 Kp / 阻尼 Kd
L0 → 电机 三相电压（PWM 占空比）
反向 编码器角度、电流、温度、IMU、力传感器，逐层往上汇总

第 4 步：插补：慢目标怎么变成快指令

L2 每 100 ms 给一个新目标，L1 每 1 ms 要一个指令，中间 99 次怎么办？插补（interpolation）：在两个目标之间用直线、三次样条或最小加加速度（minimum jerk）曲线补点，再交给一个跟踪控制器追。

一个最简单的跟踪器是一阶追赶：

\[x_{k+1} = x_k + \alpha\,(x^{\text{目标}}_k - x_k),\quad 0<\alpha<1\]

\(\alpha\) 越大追得越快，但太大会过冲、抖动。下面的动画就是这件事。

怎么看：

  1. 最上面一行是 L4 任务层，整段只出 2 个子目标（第 0 秒和第 0.5 秒）。
  2. 中间是 L2 策略层，每 0.1 秒给一个新目标（阶梯线）。
  3. 下面是 L1 控制层，每 0.01 秒追一次（平滑曲线）。底部刻度越来越密，就是频率一层比一层高。

公式

量 式子 含义
周期与频率 \(T = 1/f\) 1 kHz ↔ 1 ms；50 Hz ↔ 20 ms
一阶追赶 \(x_{k+1} = x_k + \alpha(x^*_k - x_k)\) 下层追上层目标
延迟预算 \(t_{\text{反应}} \le t_{\text{感知}} + t_{\text{推理}} + t_{\text{传输}} + T_{\text{控制}}\) 一层的反应时间是一路延迟之和（第 8 章细算）

例子：一台人形机器人的一次"递杯子"

  1. L4（VLM，1 Hz）：听到"把杯子递给我" → 子任务 [找杯子, 抓杯子, 转身, 伸手递出]。
  2. L3（30 Hz）：相机看到杯子，算出它相对机器人的位置。
  3. L2（VLA，10 Hz 出一段 50 步的 action chunk）：生成手臂和手指的未来轨迹。
  4. L1（WBC，500 Hz–1 kHz）：同时满足"手跟着轨迹走"和"整个身体不摔倒"，算出每个关节的目标力矩。
  5. L0（每个关节驱动板，20 kHz）：FOC 把目标力矩变成三相电流。
  6. 安全回路一直在旁边看：有人突然靠太近 → 降速；总线心跳丢失 → 停机（第 10 章）。

数学原理

  • 采样与频率：\(T=1/f\)；奈奎斯特：要控制带宽为 \(B\) 的动态，控制频率经验上取 \(10B\)–\(20B\)。
  • 一阶低通 / 指数平滑：\(x_{k+1} = (1-\alpha)x_k + \alpha x^*_k\)。

公式清单：\(T = 1/f\)；\(x_{k+1} = x_k + \alpha(x^*_k - x_k)\)；延迟预算求和。

关键几行：

def track(target, alpha, steps, x0=0.0):
    xs = [x0]
    for _ in range(steps):
        xs.append(xs[-1] + alpha * (target - xs[-1]))   # 每步追上剩下误差的 α
    return np.array(xs)

代码里才看得到的 2 件事：

  • 误差每一步乘 \((1-\alpha)\)，所以第 k 步误差是 \((1-\alpha)^k\)：α = 0.5 时第 10 步误差 \(0.5^{10} \approx 0.001\)。测试就是这么核对的。
  • α 超过 1 时 \((1-\alpha)\) 是负数，误差每步变号：1.5、0.75、1.125……这就是讲义说的"太大会过冲、抖动"。
